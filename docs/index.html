Overview

Writing a scientific simulator with a foundation model takes repeated revision against scarce real data. SimAuthor keeps every program it writes, chooses what to revise by score, decides how to revise from a structured discrepancy report, and reuses edits that worked.

On six biomedical tasks it beats score-only search (PUCT) on all six at 100 attempts. Its simulators improve on unseen recordings, transfer to independent encoders on three of four tasks and help out-of-distribution ECG classification. Most of the gain is structural: 111 of 138 audited revisions change program structure and carry 86.1% of the improvement.

Method

  1. Select a parent from the whole pool using its rank score plus an exploration bonus (flat PUCT).
  2. Refine it with one focused edit, guided by its discrepancy report, comparison figure, the blueprint and recent mechanisms.
  3. Evaluate the child: run it and score its 100 outputs against the reference recordings.
  4. Remember edits that gain at least 0.02 by adding them to the mechanism library.

Code

The released simulators need only NumPy and SciPy. Authoring a simulator for your own task needs a model API key, a few dozen real recordings and an evaluator; the repository includes a template and guide.

# install
pip install "simauthor[audio,llm] @ git+https://github.com/yishani/SimAuthor"

# generate signals with a released simulator (no API key)
simauthor generate COPD --out samples/copd

# author a simulator for your own task: a few dozen recordings + an evaluator
export GEMINI_API_KEY=...
simauthor run --condition "Mitral regurgitation" --modality audio \
    --ref data/my_recordings --evaluator my_evaluator.py --out runs/mr

# reproduce the paper's tables from the released runs
git clone https://github.com/yishani/SimAuthor && python SimAuthor/experiments/reproduce.py

Scope

Search scores measure agreement between simulated and real signal distributions. They do not establish physiological or mechanistic fidelity, and the model can only correct discrepancies the evaluator exposes. All data are public, de-identified research datasets used under their original licences; no recordings are redistributed. We make no diagnostic or clinical claims.
